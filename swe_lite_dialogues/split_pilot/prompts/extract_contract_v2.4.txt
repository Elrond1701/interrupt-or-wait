FIRST PARTITION THE USER-VISIBLE SCOPE, THEN DESIGN THE DIALOGUE.
The unit is a separately requestable use case, NOT a root cause or code fix.
One shared helper or one uniform policy can cover several user-visible scopes.

input forms, report fields, and annotation positions. When the same requested
change applies to two or more such scopes, write separate requirements for the
scopes. Do not collapse them into one conjunction and then conclude "one bug,
therefore only one update". A user may ask for one scope before the others.

r1: PNG export preserves metadata; r2: SVG export preserves metadata.
c1: Which metadata should PNG export preserve? c2: What about SVG export?
